# Project overview

RehabMotion AI is an educational R&D prototype for quantifying simple rehabilitation movements from standard video.

## Delivered phases

1. **Video ingestion** - validated upload, preview and metadata.
2. **Pose estimation** - MediaPipe landmarks, quality checks and annotated preview.
3. **2D kinematics** - knee, hip and trunk signals with visibility-aware smoothing.
4. **Repetitions** - complete-cycle detection, phases and per-repetition metrics.
5. **Dashboard** - persistent analysis, summaries, warnings, charts and CSV exports.
6. **PDF report** - three-page A4 report with metrics, curves and limitations.
7. **Portfolio** - reproducible demo assets, architecture diagram, GitHub CI and recruiter-oriented documentation.

The seven-phase roadmap is complete. Future work focuses on validation, uncertainty, longitudinal comparison and 3D/sensor-fusion methods rather than expanding the prototype with clinical claims.
